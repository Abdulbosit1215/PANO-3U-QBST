# PANO-3U Software Package

Version B / 2026-09 — Complete dual-fisheye panoramic CubeSat software stack.

## Components

```
software/
├── docs/通信协议规范.md            Inter-board + UHF protocol format/commands/error codes
├── payload_cm4/                   ★ On-orbit payload software (CM4, Python3, Raspberry Pi OS)
│   ├── main.py                    Main program/state machine/systemd entry
│   ├── camera.py                  Dual-fisheye synchronized capture (picamera2, RAW+H.265)
│   ├── stitch.py                  Panoramic stitching core (projection + weighted overlap blend)
│   ├── storage.py                 File registration/chunking/power-loss protection/reclamation
│   ├── link.py                    OBC link (HDLC framing + CRC16, streaming decode)
│   ├── config.py                  Parameter table (updatable in orbit)
│   └── tests/                     Unit tests
├── obc_firmware/                  ★ OBC firmware (STM32F405, C/HAL/FreeRTOS)
│   └── Core/{Src,Inc}/            main/fsm/adcs/comm/payload_mgr/drivers/log
└── ground_station/                ★ Ground station (Python3)
    ├── ground_station.py          Controller (Direwolf KISS integration)
    ├── receiver.py                AX.25 parsing + downlink decode
    ├── image_assemble.py          Chunk reassembly/resume/power-loss recovery
    ├── stitch_ground.py           Ground high-quality stitch
    ├── calibrate.py               Factory calibration tool
    └── pass_predict.py            Pass prediction (TLE+SGP4)
```

## Deployment

**CM4 payload side**:
```bash
sudo cp -r payload_cm4 /opt/pano3u/
sudo systemctl enable /opt/pano3u/pano3u-payload.service
# Put calibration.json generated by factory calibration in /opt/pano3u/
```

**OBC**: see `obc_firmware/README.md` (CubeMX/PlatformIO build).

**Ground station** (Linux + RTL-SDR or UHF radio audio path):
```bash
pip install opencv-python numpy skyfield pyserial
direwolf -t 0 -r 48000 -
python3 ground_station/ground_station.py --kiss 127.0.0.1:8001
```

## Suggested Integration Test Sequence

1. `pytest payload_cm4/tests/` — protocol/storage/stitch unit tests on PC
2. Desktop integration: CM4 hardware + serial bridge against OBC protocol simulator
3. Dual-camera calibration: run `calibrate.py` to generate `calibration.json`
4. Space-ground link test: beacon TX and ground decode verification
5. Full spacecraft integration test: re-verify capture/downlink after vibration and TVAC

## Key Performance Targets

- Capture to panoramic output: ~8 s (5760×2880, includes dual RAW capture)
- Video: dual 4K30 H.265, 25 Mbps per stream
- Downlink per pass: ~400 KB (9.6 kbps × 8 min × 70% efficiency)
- ~5 MB panorama transfer: about 12 passes
- Resume support: chunk bitmap + selective retransmission, supports cross-pass resume
